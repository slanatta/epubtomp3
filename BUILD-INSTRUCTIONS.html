EPUB to MP3

A rebuilt version of your friend's converter, packaged as a Windows installer. The finished program needs no Python, no virtual environment, and no internet after the first launch.

What changed from the original. The old script was a small window that ran a separate kokoro-tts command, which is why it needed Python, a virtual environment, and a hunt through folders to find things. This version has the speech engine built into it. Same voices, no plumbing.

Don't want to install anything? Open GITHUB-BUILD.html instead. GitHub's Windows servers can do the whole build for free — you upload the folder, press a button, and download the finished installer. This page covers the local route.

What you need on the build machine

ToolWhereWhy
Python 3.12 python.org/downloads Only to build. Tick Add python.exe to PATH during setup. 3.11 and 3.13 also work.
Inno Setup 6 jrsoftware.org/isdl.php Turns the built folder into Setup.exe. Free. Default install options are fine.

Neither is needed on the computers that will run the program. Roughly 3 GB of free disk space during the build, and about 15 minutes.

Building it

  1. Unzip this folder somewhere simple — C:\epub2mp3 is ideal. Avoid OneDrive-synced folders and paths with accented characters; both occasionally confuse PyInstaller.
  2. Double-click build.bat. A console window opens and works through six steps. The dependency download is the slow part.
  3. Collect the output from dist\:
    • EpubToMP3-1.0.0-Setup.exe — the installer, roughly 90–130 MB. This is the thing to hand to people.
    • EpubToMP3\ — the same program as a plain folder. Copy it to a USB stick and it runs anywhere, no install needed.

If your antivirus interrupts the build, add an exclusion for the project folder and run build.bat again. PyInstaller assembles an executable at runtime, which heuristic scanners dislike on principle. It is a false positive, but a persistent one.

Building without Inno Setup

If Inno Setup is missing, build.bat says so and stops after producing dist\EpubToMP3\. That folder is fully working — zip it and it runs on any Windows 10 or 11 machine. Install Inno Setup later and re-run the script to get the installer.

What people see when they run it

  1. SmartScreen warning on first launch. Unavoidable without a code-signing certificate, which costs a few hundred dollars a year. Click More info → Run anyway. It appears once.
  2. A one-time 330 MB download. The voice model, fetched on first launch with a progress bar, saved to %LOCALAPPDATA%\EpubToMP3\models. Everything after that is offline.
  3. Then it just works. Pick a book, untick the chapters you do not want, preview a voice, convert. One tagged MP3 per chapter.

For a machine that will never be online: run the program once on a connected PC, then copy %LOCALAPPDATA%\EpubToMP3\models across. Or drop the two model files into a folder named models beside EpubToMP3.exe — it looks there too.

Speed

Kokoro runs about one to three times faster than real time on a normal laptop, and it uses every core you have. A ten-hour book is typically a three to eight hour job. Conversion can be stopped and resumed: finished chapters are kept, and re-running with Skip chapters already converted ticked picks up where it left off.

What was actually tested

The application code, the frozen build, and the conversion pipeline were all executed and verified before this was sent to you:

  • Real Kokoro synthesis producing playable, correctly tagged MP3s — verified levels, duration, bitrate and ID3 tags.
  • EPUB 2 (NCX) and EPUB 3 (nav document) parsing, nested folders, broken markup, missing metadata, non-EPUB input.
  • Chapter selection, resume, mid-conversion cancellation, and recovery from a failing passage — including that no half-written files are left behind.
  • The PyInstaller bundle, run as a frozen executable, producing byte-identical audio to the source version.
  • The first-run model download, into a clean user profile with no model present.

The one piece that could not be tested here: the build ran on Linux, so the Windows-specific parts — the PyInstaller Windows bundle and the Inno Setup compile — will run for the first time on your machine. The scripts are written carefully and fail loudly rather than silently, but if something goes wrong it will be in those two steps. Send me whatever the console prints and it should be quick to sort out.

One licensing note worth reading

The program bundles espeak-ng and phonemizer, both GPL v3, so the finished executable is effectively GPL v3 too. Using it yourself or giving it to friends is fine. If you hand out the installer, hand out this source folder with it — that satisfies the licence. Selling it as closed software would not. Full detail is in LICENSE.txt.

Voices are Kokoro v1.0 (Apache 2.0). Speech runs entirely on the local CPU — no text leaves the machine.
